Sequence · Repo-as-mailbox

One round-trip, message by message

A step ships, the audit fires, the verdict lands, work resumes — and when a decision is deferred, both sides go quiet until the founder rules. Solid = a push or poll · dashed = the reply it receives.

Commit-only messages

Every letter is a commit

  • SUBMIT / REVIEW / DECISION — one timestamped file each
  • Append-only: neither side edits the other's mail
  • The audit trail is the git log itself

Why polling

No runtime, no API between them

  • Both sides watch origin/main via a marker hash
  • Idle tick = zero tokens; a changed marker = one wake
  • Never poll HEAD in a shared working tree — always origin

The stop state

AWAITING_FOUNDER silences both

  • A deferred decision pauses the ring — not just one side
  • The founder writes a DECISION letter into the same box
  • The ruling wakes the loop; no human relay needed
